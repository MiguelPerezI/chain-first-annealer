4).- On "\begin{corollary}[all boundary-of-simplex " we have this obsercation: [M-01, propuesta matemática para revisión de los autores; derivada en esta revisión, no extraída de los commits; conteo contrastado exhaustivamente para n=1..6] \begin{lemma} Let $K=\partial\Delta^{n+1}$, $n\geq1$, and $N=n+2$. The maximum number of ordered base-facet pairs covered by two star rectangles is $N^2-2$. Consequently, their maximum coverage in maximal product facets is \[ (N^2-2)\binom{2n}{n}. \] \end{lemma} \begin{proof} Index the facets by $s_a=V\setminus\{a\}$. The rectangle $D(v,w)$ covers $(s_a,s_b)$ exactly when $a\ne v$ and $b\ne w$. For $D(v,w)$ and $D(v',w')$ with $v\ne v'$ and $w\ne w'$, the only missed pairs are $(s_v,s_{w'})$ and $(s_{v'},s_w)$. If the first coordinates coincide, an entire row of $N$ pairs is missed; if the second coordinates coincide, an entire column is missed. Since $N\geq3$, no pair covers more than $N^2-2$ pairs, and $D(0,0)$ together with $D(1,1)$ attains this bound. Every base-facet pair contains $\binom{2n}{n}$ maximal staircase simplices, giving the stated facet count. \end{proof} -- Para n=2,3,4 recupera 84, 460, 2380. a- REVIEW NOTE B (reproducibility). In the local copies reviewed, the repository simplicial-complexity-certificates contains the certificates but NOT the scripts this paragraph says it contains; the code lives in chain-first-annealer/opti. Suggestion: link both repositories and pin commit hashes or an archived release (e.g. Zenodo DOI). The current online state was not checked in this review, so please verify before claiming the two coincide.
b- REVIEW NOTE C (repository validation). Two failures were reproduced locally. (1) reproduce_all.sh uses set -e without pipefail; piping the auditor into tail can mask a nonzero exit status. (2) verify_system relies on assert, which is stripped by python -O, so the exporter could mark an invalid certificate as verified. Note the independent auditor DID reject the deliberately invalid test certificate, and neither issue shows that the published certificates are wrong. Suggestion: explicit validation and error propagation in both places. No code was edited from Overleaf.
c- REVIEW NOTE D (experimental evidence). The stored timings are evidence about particular executions, not performance guarantees. Please add: several seeds per target and the resulting success rates; comparable move/time budgets across rows so the comparison is like-for-like; exact software and hardware versions (CUDA, driver, Numba, Python, GPU model); and a separation of build time, search time and audit time. As it stands a single seed per row cannot support claims about typical behaviour.
d- REVIEW NOTE E (mathematical scope). A failed search is not a proof of nonexistence. The impossibility of a two-domain cover for the S^3 model remains open after this review, so please keep upper bounds as upper bounds and do not promote them to equalities without a matching lower bound. This review also establishes no bibliographic priority: novelty with respect to the literature was not checked exhaustively, so any claim of being first should be stated cautiously or dropped.
e- REVIEW NOTE F (C2 needs revision; left unchanged on purpose). C2 is stated universally (searches with k<rho chains ALWAYS converge to (sub)rectangle covers), and the saved states do not support the rectangle part: see the runs now listed in Section 4 (s3_k2_A, s3_k2_v2_point, s4_k2_v2), whose domains are not rectangles and whose unions are not unions of two rectangles. What is reproducible is the COVERAGE VALUE, not the product structure. Also, if the statement is meant to include n=1 it must be reconciled with the circle: there rho=3 while two valid domains exist. We did not rewrite C2 because a replacement conjecture is the authors' call.
