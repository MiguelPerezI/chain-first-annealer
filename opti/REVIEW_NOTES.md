It preserves historical certificates and timing records. It does not establish

## The three methods

Ortiz, Lara, González and Borat's 2021 method searches a contiguity chain on a
prescribed domain, growing domains through LocalSearch. The optimized
LocalSearch in `src/gpu_sc.py` changes the proposal rule, enumerates admissible
values and stops when the target is contiguous. The separate chain-first kernel
searches entire systems of vertex-map sequences and derives their domains.
The beta/gamma energy diagnosis concerns versions of this annealer, not a
penalty present in the original paper's LocalSearch.

A candidate sequence has `cmax + 1` vertex maps and `cmax` links. Its interior
maps need not be simplicial globally. A chain is valid on the subcomplex
generated by the facets on which every link is contiguous. Restriction to that
subcomplex supplies the simplicial maps in the exported certificate.

For link-defect counts `b[j,f]`, the actual energy is

```
m[f] = min_j b[j,f]
pen(0) = 0; pen(b) = 1 + beta*b for b > 0
E = sum_f weights[f]*pen(m[f]) + gamma*sum_j,f b[j,f]
coverage = count(f where m[f] == 0)
```

Initial sequences sweep entries from pi1 to pi2. Mutations change one vertex
across one or several consecutive interior maps. Temperature decays within an
epoch; population selection occurs between epochs. The incumbent maximizes
unweighted coverage. Guided search changes facet weights and their cap;
`--guide-max` from the newer experiments is retained.

## Counts do not determine the shape of a domain

The recorded `s3_k2_v2_track` state is exactly two rectangles of 320 facets
whose union has 460 facets. This does not hold for every 460-state:

| Run | Domain sizes | Facet pairs touched / fully covered by the union | Union is two rectangles |
|---|---|---|---|
| s3_k2_A | 284, 265 | 24 / 22 | no |
| s3_k2_v2_track | 320, 320 | 23 / 23 | yes |
| s3_k2_v2_point | 297, 317 | 25 / 21 | no |
| s4_k2_v2 | 1746, 1750 | 35 / 33 | no |

On S³ a rectangle touches 16 base-facet pairs. The 265-facet domain in
`s3_k2_A` touches 20, so it cannot even be contained in a rectangle. On S⁴,
2380/2520 equals 34/36 numerically but is not necessarily 34 fully covered
pairs. The circle already has a verified two-domain cover although rho=3;
a universal C2 including the circle must account for this counterexample.
C1 remains a conjecture, meaning that two domains do **not** suffice if
SC_strict(∂Δ⁴)=2. Neither failed searches nor a finite chain-length budget
establish that assertion.

The raw-state checker and hashed evidence are maintained in
[Abstract_Motion_GPU](https://github.com/MiguelPerezI/Abstract_Motion_GPU),
`scripts/review_chain_first_artifacts.py` and `docs/review_20260920/evidence.json`.
The explicit three-star construction remains valid independently of these
empirical interpretations.

## Runtime guarantees and checks

`verify_system` and certificate export use explicit exceptions, including under
`python -O`. The writer validates before creating files and rejects metadata
that overrides certificate fields. New exports record source hashes, revision,
Python/package versions and the hash of a continuation input when supplied.
This provenance describes the current export, not unrecorded historical runs.
`certification.independent_audit = "not_run"` remains honest until a separate
auditor runs; an internal pass is not an independent certification.

`cmax` is restricted to 2..255 because defect counters are uint8. Counts,
probabilities, temperatures and guide parameters are checked before GPU access.

A completed but incomplete search writes `status: incomplete`, no bound and no
certificate. It retains exit 0 for compatibility with exploratory campaign
scripts. Pass `--require-cover` to return exit 2 for that case. Invalid arguments
also use argparse's exit 2, so the reproduction control requires both that code
and a fresh, valid incomplete-run JSON record. Other failures abort. Incomplete
runs cannot overwrite an output directory containing a certificate.

`reproduce_all.sh` uses pipefail and propagates auditor errors. It uses the
`src/` layout and accepts `PY=/absolute/path/to/python`; the default is python3.
Install dependencies from the repository root with `python3 -m pip install -r
requirements.txt`. The historical campaign scripts in `scripts/` are not the
canonical reproduction entry point and have not all been migrated or retested.
Use a disposable checkout for reproduction: the canonical script regenerates
named result directories.

CPU regression suite:

```bash
python3 -B opti/src/test_contracts.py
python3 -O -B opti/src/test_contracts.py
```

These tests validate rejection paths, valid exports, independent auditing,
parameter bounds and incomplete-run handling. They do not rerun GPU searches.
